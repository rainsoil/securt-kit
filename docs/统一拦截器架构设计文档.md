# Field-Encryptor 统一拦截器架构设计文档

## 1. 项目概述

### 1.1 设计目标
重构现有的 field-encryptor 项目，将分散的 DB 模式和 POJO 模式拦截器统一为一个优雅的架构，通过统一的字段拦截器接口实现不同加解密策略。

### 1.2 核心思想
- **统一SQL解析**：只负责解析SQL，识别表、字段、值的关系
- **统一拦截器接口**：定义一个拦截器接口，可以拦截和修改表字段和字段值
- **不同实现**：DB模式和POJO模式只需要实现这个拦截器接口，注入不同的逻辑

### 1.3 技术栈
- Java 8+
- Spring Boot 2.5.3+
- MyBatis 3.5.10+
- JSqlParser 4.9+
- Hutool 5.8.11+

### 2.2 核心组件说明

#### 2.2.1 UnifiedFieldInterceptor（统一字段拦截器）
- **职责**：协调SQL解析和字段处理
- **特点**：根据配置选择不同的字段拦截器实现
- **优势**：单一入口，逻辑清晰

#### 2.2.2 UnifiedSqlAnalyzer（统一SQL解析器）
- **职责**：解析SQL语句，识别表、字段、值的关系
- **特点**：只负责解析，不关心处理逻辑
- **优势**：职责单一，易于维护

#### 2.2.3 FieldInterceptor（字段拦截器接口）
- **职责**：定义字段拦截和修改的标准接口
- **特点**：支持值拦截和字段名拦截
- **优势**：接口简单，易于扩展

## 3. 详细设计

### 3.1 数据模型设计

#### 3.1.1 FieldContext（字段上下文）
```java
public class FieldContext {
    // 核心信息
    private String tableName;           // 表名
    private String fieldName;           // 字段名
    private FieldPosition position;     // 字段位置
    private SqlType sqlType;           // SQL类型
    
    // 可选信息
    private Object value;               // 字段值
    private FieldEncryptor annotation;  // 加密注解
    private Integer parameterIndex;     // 参数索引
    private String propertyName;        // 属性名
    
    // 处理标识
    private boolean needEncrypt;        // 是否需要加密
    private boolean needDecrypt;        // 是否需要解密
}
```

#### 3.1.2 SqlAnalysisResult（SQL分析结果）
```java
public class SqlAnalysisResult {
    private String originalSql;                                    // 原始SQL
    private Statement statement;                                    // 解析后的Statement
    private SqlType sqlType;                                       // SQL类型
    private List<FieldContext> fieldContexts;                      // 所有字段上下文
    private Map<String, List<FieldContext>> tableFieldMap;         // 表字段映射
    private Set<String> encryptFields;                             // 需要加密的字段
    private Set<String> decryptFields;                             // 需要解密的字段
    private Map<String, FieldContext> placeholderMap;              // 占位符映射
    private boolean needProcess;                                   // 是否需要进行处理
}
```

### 3.2 接口设计

#### 3.2.1 FieldInterceptor接口
```java
public interface FieldInterceptor {
    
    /**
     * 拦截字段值
     * 用于POJO模式，直接对值进行加密/解密
     */
    Object interceptFieldValue(FieldContext context);
    
    /**
     * 拦截字段名
     * 用于DB模式，将字段名替换为加密/解密函数
     */
    String interceptFieldName(FieldContext context);
    
    /**
     * 获取拦截器名称
     */
    String getInterceptorName();
    
    /**
     * 判断是否支持当前字段
     */
    default boolean supports(FieldContext context) {
        return true;
    }
}
```
