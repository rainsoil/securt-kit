# 字段加密器使用说明

## 概述

字段加密器是securt-kit项目的核心组件之一，提供了统一的SQL字段拦截和加密/解密功能。该组件基于架构设计文档实现，支持DB模式和POJO模式两种加解密策略。

## 核心组件

### 1. UnifiedFieldInterceptor（统一字段拦截器）
- **职责**：协调SQL解析和字段处理
- **特点**：根据配置选择不同的字段拦截器实现
- **优势**：单一入口，逻辑清晰

### 2. UnifiedSqlAnalyzer（统一SQL解析器）
- **职责**：解析SQL语句，识别表、字段、值的关系
- **特点**：只负责解析，不关心处理逻辑
- **优势**：职责单一，易于维护

### 3. FieldInterceptor（字段拦截器接口）
- **职责**：定义字段拦截和修改的标准接口
- **特点**：支持值拦截和字段名拦截
- **优势**：接口简单，易于扩展

## 支持的SQL类型

- **SELECT**：查询语句，支持字段解密
- **INSERT**：插入语句，支持字段加密
- **UPDATE**：更新语句，支持字段加密
- **DELETE**：删除语句，支持条件字段处理

## 配置说明

### 1. 启用字段加密器

在`application.yml`中添加配置：

```yaml
securt-kit:
  field-encryptor:
    enabled: true
    mode: db  # 可选值: db, pojo
```

### 2. 模式说明

#### DB模式（mode: db）
- 通过数据库函数进行加解密
- 修改SQL语句，将字段名替换为加密/解密函数
- 适用于数据库层面加解密

#### POJO模式（mode: pojo）
- 直接对Java对象的值进行加解密
- 不修改SQL语句
- 适用于应用层面加解密

## 使用方法

### 1. 基本使用

```java
@Autowired
private UnifiedFieldInterceptor fieldInterceptor;

// 拦截并处理SQL
String originalSql = "SELECT id, name, email FROM users WHERE age > 18";
String processedSql = fieldInterceptor.interceptSql(originalSql);
```

### 2. 注解使用

在实体类字段上添加注解：

```java
@TableEncryptor
public class User {
    
    @FieldEncryptor
    private String email;
    
    @FieldEncryptor
    private String phone;
    
    // 其他字段...
}
```

### 3. 自定义拦截器

实现`FieldInterceptor`接口：

```java
@Component
public class CustomFieldInterceptor implements FieldInterceptor {
    
    @Override
    public Object interceptFieldValue(FieldContext context) {
        // 自定义值处理逻辑
        return context.getValue();
    }
    
    @Override
    public String interceptFieldName(FieldContext context) {
        // 自定义字段名处理逻辑
        return context.getFieldName();
    }
    
    @Override
    public String getInterceptorName() {
        return "CustomFieldInterceptor";
    }
    
    @Override
    public int getOrder() {
        return 50; // 优先级
    }
}
```

## 示例代码

### 1. SQL解析示例

```java
@Autowired
private UnifiedSqlAnalyzer sqlAnalyzer;

String sql = "SELECT id, name, email FROM users WHERE age > 18";
SqlAnalysisResult result = sqlAnalyzer.analyze(sql);

System.out.println("SQL类型: " + result.getSqlType());
System.out.println("字段数量: " + result.getFieldContexts().size());
result.getFieldContexts().forEach(field -> 
    System.out.println("字段: " + field.getFieldName() + 
                    ", 位置: " + field.getPosition())
);
```

### 2. 字段拦截示例

```java
@Autowired
private UnifiedFieldInterceptor fieldInterceptor;

// 处理SELECT语句
String selectSql = "SELECT id, name, email FROM users WHERE age > 18";
String processedSelect = fieldInterceptor.interceptSql(selectSql);

// 处理INSERT语句
String insertSql = "INSERT INTO users (name, email) VALUES (?, ?)";
String processedInsert = fieldInterceptor.interceptSql(insertSql);

// 处理UPDATE语句
String updateSql = "UPDATE users SET name = ? WHERE id = ?";
String processedUpdate = fieldInterceptor.interceptSql(updateSql);

// 处理DELETE语句
String deleteSql = "DELETE FROM users WHERE id = ?";
String processedDelete = fieldInterceptor.interceptSql(deleteSql);
```

## 高级功能

### 1. 复杂SQL支持

支持复杂的SQL语句，包括：
- JOIN查询
- 子查询
- 聚合函数
- 条件表达式
- 排序和分组

### 2. 字段位置识别

能够识别字段在SQL中的位置：
- SELECT_FIELD：SELECT子句中的字段
- WHERE_FIELD：WHERE子句中的字段
- INSERT_FIELD：INSERT子句中的字段
- UPDATE_FIELD：UPDATE子句中的字段
- 等等...

### 3. 优先级管理

拦截器支持优先级配置，数值越小优先级越高：

```java
@Override
public int getOrder() {
    return 100; // 较低优先级
}
```

## 注意事项

1. **性能考虑**：SQL解析会带来一定的性能开销，建议在生产环境中谨慎使用
2. **SQL兼容性**：目前主要支持标准SQL语法，某些数据库特定的语法可能不支持
3. **错误处理**：解析失败时会返回原始SQL，确保系统稳定性
4. **扩展性**：可以通过实现`FieldInterceptor`接口来扩展自定义逻辑

## 故障排除

### 1. 常见问题

**Q: SQL解析失败怎么办？**
A: 检查SQL语法是否正确，查看日志中的错误信息

**Q: 拦截器不生效？**
A: 检查配置是否正确，确认拦截器是否被正确注册

**Q: 性能问题？**
A: 考虑使用缓存机制，或者只对关键字段启用加密

### 2. 日志查看

组件会输出详细的日志信息，包括：
- SQL解析过程
- 字段识别结果
- 拦截器处理过程
- 错误信息

## 总结

字段加密器提供了完整的SQL字段拦截和加解密解决方案，通过三个核心组件的协作，实现了灵活、可扩展的字段处理架构。无论是DB模式还是POJO模式，都能满足不同的业务需求。
